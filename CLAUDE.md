# undangan-broadcast

**Status**: Tool Aktif
**Kategori**: Tool — Undangan Digital

## Deskripsi
Website undangan (khitan, wisuda, kelulusan, dll) digital berbasis Astro. Proyek personal akan dikembangkan dan diintegrasikan dengan sistem whatsapp dan payment.  desain dan sistem mengikuti wedding-invitation.

## Tech Stack
- Astro, generate.sh

## Catatan
- generate.sh: script untuk generate undangan dari data CSV/JSON
- Terintegrasi dengan whatsapp-service untuk pengiriman massal, dan dengan payment-gateway untuk pembayaran.
